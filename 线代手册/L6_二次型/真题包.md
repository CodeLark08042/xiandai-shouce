## 真题明细（基础篇 1987—2008）

### [1990, 八题, 8分] 正交变换化标准形
- **题目原文**：求一个正交变换化二次型 $f=x_1^2+4x_2^2+4x_3^2-4x_1x_2+4x_1x_3-8x_2x_3$ 为标准形。
- **答案摘要**：$A=\begin{pmatrix}1&-2&2\\-2&4&-4\\2&-4&4\end{pmatrix}$，特征值 $\lambda_1=\lambda_2=0,\lambda_3=9$，标准形 $f=9y_3^2$。
- **来源**：基础篇题目 p194 / 答案 p173。OCR状态：已核对。

### [1993, 七题, 8分] 正交变换反求参数与正交矩阵
- **题目原文**：$f(x_1,x_2,x_3)=2x_1^2+3x_2^2+3x_3^2+2a x_2x_3\ (a>0)$，通过正交变换化成标准形 $f=y_1^2+2y_2^2+5y_3^2$，求参数 $a$ 及所用正交变换矩阵。
- **答案摘要**：$a=2$；$A$ 特征值 $1,2,5$；正交矩阵由单位化特征向量 $(0,1,-1),(1,0,0),(0,1,1)$ 构成。
- **来源**：基础篇题目 p194 / 答案 p174-175。OCR状态：已核对。

### [1996, 九题, 8分] 二次型秩 / 特征值 / 二次曲面
- **题目原文**：$f=5x_1^2+5x_2^2+c x_3^2-2x_1x_2+6x_1x_3-6x_2x_3$ 的秩为 2。(1)求 $c$ 及对应矩阵特征值；(2)指出 $f=1$ 表示何种二次曲面。
- **答案摘要**：$c=3$；特征值 $0,4,9$；$f=1$ 即 $4y_2^2+9y_3^2=1$ 为椭圆柱面。
- **来源**：基础篇题目 p194 / 答案 p175。OCR状态：已核对。

### [1998, 十题, 6分] 二次曲面正交变换
- **题目原文**：$x^2+a y^2+z^2+2bxy+2xz+2yz=4$ 经正交变换化为椭圆柱面 $\xi^2+4\eta^2=4$，求 $a,b$ 与正交矩阵 $P$。
- **答案摘要**：由迹 $1+a+1=0+1+4$ 与 $|A|=-(b-1)^2=0$ 得 $a=3,b=1$；特征值 $0,1,4$。
- **来源**：基础篇题目 p195 / 答案 p175-176。OCR状态：已核对。

### [2002, 一(4)题, 3分] 标准形反求参数
- **题目原文**：实二次型 $f=a(x_1^2+x_2^2+x_3^2)+4x_1x_2+4x_1x_3+4x_2x_3$ 经正交变换 $x=Py$ 化为标准形 $f=6y_1^2$，求 $a$。
- **答案摘要**：标准形系数即特征值 $6,0,0$，由 $3a=6$ 得 $a=2$。
- **来源**：基础篇题目 p195 / 答案 p176。OCR状态：已核对。

### [2005, 20题, 9分] 秩 / 正交变换 / $f=0$ 的解
- **题目原文**：$f=(1-a)x_1^2+(1-a)x_2^2+2x_3^2+2(1+a)x_1x_2$ 秩为 2。(I)求 $a$；(II)求正交变换 $x=Qy$ 化标准形；(III)求 $f=0$ 的解。
- **答案摘要**：$a=0$；特征值 $2,2,0$，标准形 $2y_1^2+2y_2^2$；$f=0$ 解为 $x=k(1,-1,0)^T$。
- **来源**：基础篇题目 p196 / 答案 p176-177。OCR状态：已核对（书页页眉误标"数学二"，但本书考频表将其列入数一，按权威口径收录）。

### [2008, 6题, 4分] 二次曲面图形判正特征值个数
- **题目原文**：$A$ 为三阶实对称矩阵，二次曲面方程 $x^TAx=1$ 在正交变换下标准方程图形为双叶双曲面，问 $A$ 的正特征值个数。
- **答案摘要**：双叶双曲面标准方程 $x^2/a^2-y^2/b^2-z^2/c^2=1$，正惯性指数 $p=1$，选 **B**。
- **来源**：基础篇题目 p196 / 答案 p177。OCR状态：已核对。

### [1991, 八题, 6分] 正定矩阵证明
- **题目原文**：设 $A$ 是 $n$ 阶正定矩阵，$E$ 是 $n$ 阶单位矩阵，证明 $|A+E|>1$。
- **答案摘要**：$A$ 特征值 $\lambda_i>0$，$|A+E|=\prod(1+\lambda_i)>1$。
- **来源**：基础篇题目 p197 / 答案 p177。OCR状态：已核对。

### [1999, 十一题, 6分] 正定充要条件
- **题目原文**：$A$ 为 $m$ 阶实对称正定矩阵，$B$ 为 $m\times n$ 实矩阵，证明 $B^TAB$ 正定 $\Longleftrightarrow r(B)=n$。
- **答案摘要**：必要性：$\forall x\ne0,\ (Bx)^TA(Bx)>0\Rightarrow Bx\ne0$，故 $Bx=0$ 只有零解 $r(B)=n$；充分性：$r(B)=n$ 时 $Bx=0$ 只有零解。
- **来源**：基础篇题目 p197 / 答案 p178。OCR状态：已核对。

### [2001, 二(4)题, 3分] 合同且相似（选择）
- **题目原文**：$A$ 为 4 阶元素全为 1 的矩阵，$B=\mathrm{diag}(4,0,0,0)$，问 $A$ 与 $B$ 的关系。
- **答案摘要**：$A$ 特征值 $4,0,0,0$，实对称必可相似对角化，故相似；相似必有相同正负惯性指数故合同。选 **A**。
- **来源**：基础篇题目 p199 / 答案 p179。OCR状态：已核对。

### [2007, 8题, 4分] 合同但不相似（选择）
- **题目原文**：$A$ 为三对角矩阵 $\begin{pmatrix}2&-1&0\\-1&2&-1\\0&-1&2\end{pmatrix}$，$B=\mathrm{diag}(1,1,0)$，问 $A$ 与 $B$ 关系。
- **答案摘要**：迹 $\sum a_{ii}\ne\sum b_{ii}$ 故不相似；$A$ 特征值 $3,3,0$，$p=2,q=0$，与 $B$ 相同故合同。选 **B**。
- **来源**：基础篇题目 p199 / 答案 p179。OCR状态：已核对。

### [2009, 21题, 11分] 规范形反求参数
- **题目原文**：$f=a x_1^2+a x_2^2+(a-1)x_3^2+2x_1x_3-2x_2x_3$。(I)求 $f$ 矩阵所有特征值；(II)若规范形为 $y_1^2+y_2^2$，求 $a$。
- **答案摘要**：特征值 $a,a+1,a-2$；规范形 $p=2,q=0$ 要求特征值符号为 $+,+,0$，最小者 $a-2=0$，故 $a=2$。
- **来源**：提高篇题目 p059 / 答案 p129。OCR状态：已核对。

### [2010, 21题, 11分] 反求矩阵 A + 证 A+E 正定
- **题目原文**：$f=x^TAx$ 在正交变换 $x=Qy$ 下标准形 $y_1^2+y_2^2$，且 $Q$ 第 3 列为 $(\frac{\sqrt2}{2},0,\frac{\sqrt2}{2})^T$。(I)求 $A$；(II)证明 $A+E$ 正定。
- **答案摘要**：$A=\begin{pmatrix}1/2&0&-1/2\\0&1&0\\-1/2&0&1/2\end{pmatrix}$；特征值 $1,1,0$，$A+E$ 特征值 $2,2,1>0$ 故正定。
- **来源**：提高篇题目 p060 / 答案 p129-130。OCR状态：已核对。

### [2011, 13题, 4分] 二次曲面反求参数

### [2012, 21题, 11分] $A^TA$ 秩 / 正交变换

- **答案摘要**：$r(A^TA)=r(A)=2\Rightarrow a=-1$；$A^TA$ 特征值 $0,2,6$，标准形 $2y_2^2+6y_3^2$。
- **来源**：提高篇题目 p060 / 答案 p130-131。OCR状态：已核对。

### [2013, 21题, 11分] 矩阵表达式证明 / 标准形
- **题目原文**：$f=2(a_1x_1+a_2x_2+a_3x_3)^2+(b_1x_1+b_2x_2+b_3x_3)^2$，记 $\alpha,\beta$。(I)证明 $f$ 对应矩阵为 $2\alpha\alpha^T+\beta\beta^T$；(II)若 $\alpha,\beta$ 正交且均为单位向量，证明标准形为 $2y_1^2+y_2^2$。
- **答案摘要**：$A\alpha=2\alpha,\ A\beta=\beta$，$r(A)\le2<3$ 故 $\lambda_3=0$；标准形 $2y_1^2+y_2^2$。
- **来源**：提高篇题目 p061 / 答案 p131-132。OCR状态：已核对。

### [2014, 13题, 4分] 负惯性指数求参数范围

### [2020, 20题, 11分] 正交变换反求参数与 Q
- **题目原文**：$f(x_1,x_2)=x_1^2-4x_1x_2+4x_2^2$ 经正交变换 $\binom{x_1}{x_2}=Q\binom{y_1}{y_2}$ 化为 $g=a y_1^2+4y_1y_2+b y_2^2$，$a\ge b$。(I)求 $a,b$；(II)求正交矩阵 $Q$。
- **答案摘要**：$A=\begin{pmatrix}1&-2\\-2&4\end{pmatrix}\sim B=\begin{pmatrix}a&2\\2&b\end{pmatrix}$，由 $a+b=5,ab=4$ 及 $a\ge b$ 得 $a=4,b=1$；$Q=\begin{pmatrix}0&1\\-1&0\end{pmatrix}$。
- **来源**：提高篇题目 p063 / 答案 p135。OCR状态：已核对。

### [2023, 21题, 12分] 合同（可逆变换）/ 正交变换存在性
- **题目原文**：$f=x_1^2+2x_2^2+2x_3^2+2x_1x_2-2x_1x_3$，$g=y_1^2+y_2^2+y_3^2+2y_2y_3$。(I)求可逆变换 $x=Py$ 将 $f$ 化为 $g$；(II)是否存在正交变换 $x=Qy$ 将 $f$ 化为 $g$？
- **答案摘要**：(I) 两二次型规范形均为 $z_1^2+z_2^2$，$P=\begin{pmatrix}1&-1&1\\0&1&0\\0&0&1\end{pmatrix}$ 即可；(II) 不存在——若正交变换则 $A\sim B$，但 $B$ 特征值 $0,1,2$，而 $|A-E|\ne0$ 说明 $1$ 不是 $A$ 的特征值，不相似。
- **来源**：提高篇题目 p064 / 答案 p137-138。OCR状态：已核对。
